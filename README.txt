Revision Room: installable version

Put these files on a web host, keeping the icons folder as it is.

GitHub Pages (free):
1. On github.com, create a new public repository, for example "revision-room".
2. Click Add file, then Upload files, and drag in everything from this folder
   (index.html, sw.js, manifest.webmanifest, pdf.min.js, pdf.worker.min.js and the icons folder). Commit.
3. Go to Settings, then Pages. Under Build and deployment choose "Deploy from a branch",
   pick the main branch and the / (root) folder, and save.
4. After a minute the address appears there: https://YOUR-NAME.github.io/revision-room/
5. Open it on your phone and check that "Add to Home Screen" (iPhone) or "Install app" (Android) works.

Nothing private is in these files. Lessons live only on each student's device.

To publish a new version later, upload the changed files again. Open students' apps pick it up the second time they launch.
